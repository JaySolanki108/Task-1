# Nmap and Wireshark Basics

## Description
This repository contains a basic cybersecurity task focused on network scanning and traffic analysis using Nmap and Wireshark.

## Tools Used
- Nmap
- Wireshark

## Task Performed
- Conducted a TCP SYN scan on a local network using Nmap.
- Observed and analyzed SYN packets using Wireshark.

## Files Included
- scan_results.txt – Output file generated from the Nmap scan.
- Wireshark_Nmap_SYN_Filter.png – Screenshot showing SYN packets filtered in Wireshark.
